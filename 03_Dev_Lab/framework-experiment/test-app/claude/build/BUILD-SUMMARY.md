## Architecture Notes

### Multi-module dependency graph
```
:app
 ├── :core:ui       (Compose BOM, Material 3, Coil, Lottie — all api deps)
 ├── :core:data     (domain models, repository interfaces, Hilt module)
 ├── :feature:booking
 ├── :feature:ride-selection  (depends on :feature:booking for BookingViewModel)
 ├── :feature:pricing         (depends on :feature:booking)
 └── :feature:confirmation
```

### State machine
`BookingState` transitions (sealed class, in `:core:data`):
```
Idle → LocationEntry → ScheduleEntry → RideSelection → PricingReview
                                                            ↓
                                              Confirming → Confirmed
                                                     ↘ → Error
```

### Graph-scoped ViewModel
`BookingViewModel` is scoped to the `BookingGraph` back-stack entry — not to individual composables. All 5 booking screens share the same instance, so state persists across the step-by-step flow without re-fetching.

### Color discipline
Every color value (`Color(0xFF...)`) is defined only in `ColorPalette.kt`. No hex literals appear anywhere else. Semantic roles (`colorPrimary`, `colorStateSuccess`, etc.) are accessed through `MaterialTheme.colorScheme` or `SkyRideTheme.extendedColors`.

## Build Notes & Prerequisites

1. **Google Maps API key** — Add to `local.properties`:
   ```
   MAPS_API_KEY=your_key_here
   ```
   Then reference in `app/build.gradle.kts` via `buildConfigField` and inject into
   `AndroidManifest.xml` via `manifestPlaceholders`. The `MapPlaceholder` composable
   shows a static placeholder until an API key is configured and `GoogleMap` is wired in.

2. **Kotlin Serialization** — Routes use `@Serializable` for Navigation 2.8 type-safe
   routes. The `kotlin-serialization` plugin is declared in both root and app `build.gradle.kts`.

3. **KSP** — Used for Hilt code generation (`ksp` instead of `kapt`). Requires the
   `com.google.devtools.ksp` plugin matching the Kotlin version (see `libs.versions.toml`).

4. **Minimum SDK** — Set to 26 (Android 8.0) for `java.time.*` without desugaring.
   Lower it to 21 and add `coreLibraryDesugaring` if wider compatibility is needed.

5. **Lottie / Coil** — Declared as dependencies in `:core:ui`. Actual animation JSON
   files (lottie) and image URLs (Coil) should be added when assets are available.

6. **Fake repositories** — `FakeBookingRepository` and `FakeHelicopterRepository`
   provide all stub data. To connect a real backend, implement the repository interfaces
   and rebind in `DataModule.kt` (or create a separate prod/staging Hilt module).
