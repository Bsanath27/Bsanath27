# Built-in Tools

> Core Claude Code commands that don't belong to a specific plugin.

## Commands

| Command | What It Does |
|---------|-------------|
| `/schedule` | Create, update, list, or run scheduled remote agents on a cron schedule |
| `/loop [prompt]` | Run a prompt or slash command on a recurring interval |
| `/daily` | Open or create today's daily note in vault |
| `/tldr` | Save a summary of the current conversation to the vault |
| `/simplify` | Review changed code for reuse, quality, and efficiency |
| `/commit` | Create a git commit with auto-generated message |
