# Codex

> Delegate investigations and fixes to OpenAI Codex via shared runtime.

## Commands

| Command | What It Does |
|---------|-------------|
| `/codex:rescue` | Delegate investigation, diagnosis, or fix to Codex — use when stuck or need a second opinion |
| `/codex:setup` | Check and configure local Codex CLI |

## When to Use

- Claude Code is stuck or wants a second implementation pass
- Need a deeper root-cause investigation
- Want to hand a substantial coding task to Codex through the shared runtime
