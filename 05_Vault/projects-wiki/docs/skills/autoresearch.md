# Autoresearch

> Autonomous goal-directed loops — debug, fix, learn, ship, reason, predict.

## Commands

| Command | What It Does |
|---------|-------------|
| `/autoresearch:autoresearch` | General goal-directed iteration — modify, verify, keep/discard |
| `/autoresearch:autoresearch:debug` | Autonomous bug-hunting — scientific method + iterative refinement |
| `/autoresearch:autoresearch:fix` | Iterative fix loop — repairs errors until zero remain |
| `/autoresearch:autoresearch:learn` | Auto-documentation engine — scout, learn, generate docs |
| `/autoresearch:autoresearch:security` | STRIDE threat model + OWASP Top 10 audit |
| `/autoresearch:autoresearch:scenario` | Scenario-driven use case generator |
| `/autoresearch:autoresearch:ship` | Universal shipping workflow — code, content, marketing |
| `/autoresearch:autoresearch:reason` | Multi-agent adversarial refinement — generate, critique, refine |
| `/autoresearch:autoresearch:predict` | Multi-persona swarm prediction — pre-analyze from multiple viewpoints |
| `/autoresearch:autoresearch:plan` | Interactive wizard to build scope, metric, direction & verification |

## Key Concept

All autoresearch commands follow the same loop: **modify → verify → keep or discard → repeat**. They run autonomously until the goal is met or a configurable iteration limit is hit.
