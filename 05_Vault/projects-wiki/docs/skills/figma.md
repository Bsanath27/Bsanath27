# Figma

> Autonomous wireframe generation and design automation via MCP server.

**Setup:** MCP server configured in `~/.claude/mcp.json` with personal access token.

## Capabilities

- Read and inspect Figma files, frames, and components
- Generate wireframes and layouts programmatically
- Extract design tokens (colors, typography, spacing)
- Convert designs to code specifications

## How to Use

Figma MCP is available in any Claude Code session. Reference a Figma file URL or describe what you want to design.

```
"Create a wireframe for a login page in Figma"
"Extract the color palette from [Figma file URL]"
"Inspect the component structure of [frame name]"
```
