# Obsidian Tools

> Vault operations — notes, markdown, databases, canvases, web extraction.

## Commands

| Command | What It Does |
|---------|-------------|
| `/obsidian-cli` | Read, create, search, and manage notes in Obsidian vaults |
| `/obsidian-markdown` | Create Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties |
| `/obsidian-bases` | Create and edit Obsidian Bases (.base files) with views, filters, formulas |
| `/json-canvas` | Create and edit JSON Canvas files (.canvas) with nodes, edges, groups |
| `/daily` | Open or create today's daily note in vault |
| `/vault-setup` | Interactive Obsidian vault configurator |
| `/defuddle` | Extract clean markdown content from web pages (strips nav, ads, etc.) |
| `/file-intel` | Run Gemini file processor on any folder — extracts content summaries |
