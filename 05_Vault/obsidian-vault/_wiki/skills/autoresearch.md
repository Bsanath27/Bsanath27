## What It Does
AutoResearch is a skill for quickly gathering information on a topic and synthesizing it into structured knowledge. Useful when you need to understand a domain, investigate a problem, or explore connections across your wiki.

## When to Use
- **Unknown domains**: "What's this tech stack about?"
- **Problem investigation**: "Why is this failing?"
- **Knowledge gaps**: "What am I missing about this concept?"
- **Cross-referencing**: "How does this connect to what I already know?"

## How It Works
1. **Define scope** — What do you want to research?
2. **Gather** — Search wiki, docs, external sources
3. **Analyze** — Find patterns, connections, gaps
4. **Synthesize** — Create summary with actionable insights
5. **Link** — Connect to existing knowledge in wiki

## Example Usage
```
Skill: AutoResearch
Task: Understand how Cesium.js handles real-time geospatial updates

Result:
  - Core concept: WebGL batching for 10k+ objects
  - Key pattern: WebSocket delta updates + client interpolation
  - Links: Real-Time Visualization Pipeline, Skyrik project
  - Gaps: Missing: Mobile performance constraints, battery drain strategies
```
